# Exclusão de relatórios

A exclusão é feita por confirmação visual, sem código.

1. Clique no ícone de lixeira.
2. Confirme em **Sim, excluir relatório**.
3. A frontend remove o card imediatamente e atualiza a lista consultando o PostgreSQL.

O workflow 29 precisa estar ativo. Relatórios em processamento não podem ser excluídos.
